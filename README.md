
# Film Vault

A movie browsing application built using React and Vite.

## Features
- Browse popular movies
- View movie details
- Add and remove movies from your watchlist
- Save watchlist using localStorage
- Pagination

## Technologies Used
- React
- Vite
- JavaScript
- Tailwind CSS
- TMDB API

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
